# 🚀 나만의 프롬프트 관리자 (Prompt Manager)

파이썬(Python)과 Git을 활용하여 생성형 AI(GenAI) 프롬프트를 체계적으로 등록, 분류, 검색, 관리하는 터미널 콘솔 애플리케이션입니다.

---

## 📌 1. 프로젝트 소개
- **과제명**: Python & Git 기초: Git과 함께하는 Python 첫 발자국
- **분야 / 구분**: AI 활용 학습 / 필수 (학습시간: 40시간)
- **개발 환경**: Python 3.11+, Git 2.39+, VSCode
- **목표**: 
  - 기초 파이썬 문법(자료형, 제어문, 함수, 예외 처리, 파일 입출력)을 활용한 소프트웨어 구현
  - Git 핵심 명령어(`init`, `add`, `commit`, `push`, `pull`, `checkout`, `clone`, `merge`)와 브랜치 워크플로우 숙달

---

## 🛠️ 2. 주요 기능 및 메뉴 구성

| 번호 | 기능 | 세부 설명 |
|:---:|:---|:---|
| **1** | **프롬프트 추가** | 제목, 내용, 카테고리를 입력받아 신규 등록 (빈 값 입력 방지 유효성 검사) |
| **2** | **프롬프트 목록** | 전체 프롬프트의 카테고리, 제목, 즐겨찾기(⭐) 여부 목록 출력 |
| **3** | **카테고리별 조회** | 지정된 카테고리에 속한 프롬프트만 필터링하여 조회 |
| **4** | **프롬프트 검색** | 키워드로 제목 또는 내용 부분 일치 검색 (대소문자 무관) |
| **5** | **프롬프트 상세 보기** | 전체 내용 확인 및 조회수(views) 자동 카운트 |
| **6** | **즐겨찾기 관리** | 특정 프롬프트의 즐겨찾기 상태를 토글(추가/해제) |
| **7** | **즐겨찾기 목록** | 즐겨찾기(⭐)로 지정된 프롬프트만 모아서 확인 |
| **8** | **[보너스 1] 영속화 & 내보내기** | JSON 파일(`prompts.json`) 저장/불러오기 및 Markdown 문서(`prompts_export.md`) 생성 |
| **9** | **[보너스 2] CRUD & 통계** | 프롬프트 수정/삭제 및 조회수 기준 실시간 인기 Top 5 정렬 |
| **0** | **종료** | 프로그램 안전 종료 |

## 📂 3. 프롬프트 카테고리 체계
1. **텍스트 생성**: 블로그 글, 이메일, 카피라이팅, 기사 요약 등
2. **이미지 생성**: Midjourney, DALL-E, Stable Diffusion 프롬프트
3. **영상 생성**: 쇼츠, 릴스, 광고 영상 기획 및 스크립트
4. **페르소나**: 특정 전문가(수석 아키텍트, 마케터 등) 역할 부여
5. **자동화**: 반복 업무, 데이터 파싱, 정형화 포맷 변환
6. **기타**: 직접 정의하는 사용자 지정 카테고리

## 💻 4. 설치 및 실행 방법

### 1) 실행 환경 요구사항
- Python 3.10 이상
- 별도 외부 라이브러리 설치 불필요 (Python 표준 라이브러리 `json`, `os`만 사용)

### 2) 실행 방법
```bash
# 1. 저장소 복제 (GitHub에서 내려받을 경우)
git clone https://github.com/<사용자ID>/prompt-manager.git
cd prompt-manager

# 2. 프로그램 실행
python3 prompt_manager.py
```

## 🌿 5. Git 워크플로우 및 커밋 히스토리
본 프로젝트는 **기능 단위 커밋(최소 10개 이상)** 및 **브랜치 병합(checkout, merge)** 요구사항을 준수하였습니다.

### 주요 Git 명령어 수행 내역:
- `git init`: 로컬 저장소 초기화 (`main` 브랜치 설정)
- `git add`: 작업 파일 스테이징
- `git commit`: 기능별 세분화된 의미 있는 커밋 (12개 커밋 완료)
- `git checkout -b feature/prompt-list`: 프롬프트 목록 조회를 위한 피처 브랜치 분기
- `git merge`: main 브랜치로 기능 브랜치 병합 (`--no-ff`)
- `git clone / push / pull`: 원격 저장소 연동 검증
